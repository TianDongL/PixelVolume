像素音量 / Pixel Volume 0.2.6 · Windows

安装
双击 PixelVolume-0.2.6-Windows-x64-Setup.exe，按安装向导完成安装。
安装到当前用户，不需要管理员权限。安装完成后可直接打开，也可从开始菜单搜索「像素音量」。
如果系统没有界面所需组件，安装程序会从 Microsoft 联网补齐。

首次使用
打开应用后会显示引导窗口，等待「音量键已启用」后，可以按键盘音量加、音量减或静音键，或者点击「预览音量浮窗」。
拖动像素滑块即可调整系统默认音频输出设备的音量。
「登录 Windows 时自动启动」默认关闭，请根据需要自行勾选。已有安装的选择会保留。
关闭引导窗口后，应用继续在右下角系统托盘运行。再次打开应用会回到设置窗口。

更新
在设置窗口或托盘菜单选择「检查更新」，在应用内下载并校验新版。下载完成后选择「重启并更新」，软件将退出、安装并重新打开。安装失败时保留旧版；登录启动选择和界面缓存不变。
0.2.5 及以前版本需先手动安装一次 0.2.6，此后支持应用内全量更新。

退出与卸载
右键托盘图标选择「退出像素音量」，即可恢复正常系统音量键行为。
在 Windows「设置 → 应用」中找到「像素音量」并卸载，或者运行安装目录中的 Uninstall.exe。
卸载会移除应用、对应快捷方式和本安装位置的登录启动项。界面缓存可能保留在当前用户目录。

系统范围
Windows 10 2004 或更新版本、Windows 11，x64。
已随包提供 .NET 10 运行环境，无需单独安装 .NET。
本版处理标准键盘音量键及像素浮窗滑块；耳机独立硬件音量和系统快捷设置走各自入口。
