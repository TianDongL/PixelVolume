# Pixel Volume 0.2.6

Windows 和 macOS 新增应用内全量更新：在“检查更新”中下载、校验，再由用户确认安装和重启，无需外部浏览器。

- Windows 显示下载进度，支持取消及重试；验证签名清单、大小和 SHA-256。安装器等待旧进程退出，暂存新文件并在替换失败时保留旧版，成功后重新打开。
- Mac 使用 Sparkle 原生更新界面，强制验证更新清单与安装包签名，继续使用 Developer ID 签名及 Apple 公证。后台只提示，不自动安装。
- 两端沿用 Norgate 稳定更新通道和同一份发布元数据。登录启动选择由用户决定，更新后保留。
- Mac 通用包包含 Intel x86_64 和 Apple arm64，构建目标保持 Intel macOS 10.15.7／Apple 芯片 macOS 11.0。主程序、登录助手及更新组件均保留双架构。
- 下载页增加新版升级方式说明。

0.2.5 及以前版本需要按原有方式手动安装一次 0.2.6，此后发布的新版才可以在应用内完成更新。本次是全量包更新，尚未启用差分下载。

验证范围：Windows 和 Mac 签名协议测试、Windows 下载异常与缓存校验测试、隔离目录中的 NSIS 文件替换／失败保留测试、双架构构建及 Mac 签名公证。没有进行 GUI 点击测试、真实安装替换或真实 Intel 旧系统安装测试。Windows 安装包仍未做 Authenticode 签名。
