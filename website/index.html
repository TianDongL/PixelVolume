A FEW STEPS, THEN MAKE IT YOURS

第一次见面，
很快就熟悉。

应用会带你完成首次设置。
是否开机启动，由你自己决定。

在 Windows 上

  1. 运行安装程序

    双击下载好的 EXE，按照向导完成安装。若缺少 WebView2，安装程序会联网补齐。

  2. 打开应用，跟着引导试一下

    看到“音量键已启用”后，按键盘音量键，或在应用内预览浮窗。

  3. 决定要不要随登录启动

    默认不勾选。关闭引导窗口后，应用会在右下角托盘继续运行。

在 Mac 上

  1. 拖进“应用程序”

    打开 DMG，将 Pixel Volume.app 拖入 Applications，再从“应用程序”中打开。

  2. 允许辅助功能权限

    点击引导中的“打开辅助功能设置”，允许“像素音量”，再返回应用，就能使用音量键。

  3. 把启动方式留给自己

    需要时再勾选“登录时自动启动”。应用在菜单栏待命，随时可以退出。

GOOD TO KNOW

你可能还想知道。

更新在应用里完成

从 0.2.6 开始，下载、校验、安装和重启都可以在应用内完成。安装前由你确认。

Intel Mac 的安装包在哪里？+

就在上面的“Mac 通用版”里。DMG 同时包含 Intel x86_64 和 Apple arm64，系统会使用适合你电脑的版本。

为什么 Mac 需要辅助功能权限？+

像素音量需要这项权限接管键盘音量键。权限由你在系统设置中亲自允许。新版 macOS 在“隐私与安全性 → 辅助功能”；旧版在“安全性与隐私 → 隐私 → 辅助功能”。

安装之后会自动开机启动吗？+

首次安装默认关闭。你可以在首次引导或应用设置中开启，也可以随时取消。之后升级会保留你的选择。

以后怎么升级？+

在设置窗口或托盘／菜单栏选择“检查更新”。软件会下载并校验新版，确认后自动安装并重新打开，不需要跳转浏览器。0.2.5 及更早版本需要先手动安装一次 0.2.6；之后的更新可直接在应用内完成。

退出后会影响原来的音量键吗？+

退出像素音量后，音量键恢复由系统处理。耳机自身的硬件音量或某些特殊键盘驱动，可能使用各自的控制方式。
